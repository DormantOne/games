Baby MILO v2 · AutoML with a nearest-neighbor architecture search

One button runs the whole pipeline in your browser: no server, no libraries, no patient data. Every number comes from a seeded random generator, so the same seed in the same browser reproduces the run exactly.

1 · Data Forge idle

Synthetic patients with a known answer key. Labels are drawn from true risk, so even a perfect model can't hit 100%: the oracle score is the ceiling. A locked test set is split off here and not opened until Phase 5.

2 · Feature Shake-out idle

Shuffle one input at a time on held-out folds (10 scouts, 12 shuffles each) and measure how much the score drops. Decoy columns of pure noise, scored inside the same scout, set the bar a real feature must clear. Correlated inputs are also shuffled as a group so twins can't hide each other.

3 · Landscape Navigator idle

Each architecture is a point in a 10-D space. Tested points form a nearest-neighbor graph; neighbors predict how untested points would score, and the search spends its budget where predicted score plus uncertainty is highest. The winner must sit on a broad plateau, not a lucky spike.

4 · Bagged Council idle

Seven copies of the winner, each trained on a different resample and graded only on rows it never saw. Only statistical outliers are removed. The decision threshold is set here, not on the test set.

5 · Locked-Test Verdict idle

Open the vault once. Compare against the oracle and a plain logistic regression, with confidence intervals. Patients go to human review when the council is unsure, its members disagree, or the nearest-neighbor check says the patient looks unlike anyone in training.

Phase 1 · The cohort

The oracle AUC is what the true risk formula itself scores on the test set. No model can reliably beat it; the gap to it is the room left to improve.

Phase 2 · Which inputs carry signal?

Bar = mean drop in held-out AUC when that input is scrambled (10 scouts × 12 shuffles each); white whisker = ±2 standard errors; yellow line = the average decoy. The verdict uses the edge over decoys column: inside each scout the input is compared with the decoys from that same scout, so a lucky scout can't lift everything at once. Keep if the edge is more than 2 standard errors above zero. The "truth" column is the answer key from the generator, shown so you can grade the selector.

Phase 3 · The architecture landscape

Every dot is one tested architecture, placed by a 2-D projection (PCA) of its 10-D settings vector. Lines connect each architecture to its nearest neighbors in the full 10-D space, so a long line means the flat picture is squashing two close points apart. Colour = cross-validated AUC; size = number of weights; ring = the chosen winner. Hover a dot for details.

Each dot is one evaluation in order; the line is the best score so far. Left of the dashed line: space-filling seeds. Right: points chosen by the neighbor-based search.

Phase 4 · The council

Out-of-bag (OOB) AUC grades each member only on patients left out of its resample, so it's an honest score. A member is pruned only if it falls far below the others (a failed initialization), never just for ranking last.

Phase 5 · Locked-test verdict

All scores on patients the pipeline never touched. The key row is the paired comparison with logistic regression: if its interval includes zero, the neural network has not earned its complexity on this data.

Human-review routing

The patient map projects test patients from the selected-feature space to 2-D. Fill colour = council risk (blue low → red high). Circles = ordinary test patients; triangles = a deliberately out-of-range cohort (very old, deeply hypothermic) the model never saw. Red ring = sent to human review.
