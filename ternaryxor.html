A strict 0/1/2 inference network with exactly three incoming connections per trainable neuron. The page trains independent widths, identifies the smallest repeatable width, and exposes every epoch’s losses, layer credits, accumulator changes, and stored-weight transitions.

Strict contract

What remains ternary

  • Stored connection weights: only 0, 1, or 2. A centered view w−1 gives −1, 0, or +1 only during a connection calculation.
  • Communicated signals: only 0, 1, or 2. Trainable neurons emit 0 or 2; constant buses provide 0 or 1.
  • Fan-in: every trainable hidden and output neuron has exactly three incoming connections. Input and constant buses are not neurons.
  • Arithmetic: pre-activation sums and credit memory are local integer state; neither is sent as a neuron signal.
Explicit mathematical limitation

Why ordinary chain-rule gradients stop

For the hard neuron q(z)=2 when z>0, otherwise 0, the derivative is zero away from the boundary and undefined at the boundary. With integer pre-activations, a strict calculus gradient cannot carry useful credit through this node.

This page does not pretend otherwise. It uses the clearly labeled discrete layerwise credit-assignment fallback below. Its bounded integer accumulator is learning memory, not a stored connection weight and not a communicated activation.

Learning rule

Discrete layerwise credit assignment with integer memory

output credit: cₒ = (target − output) / 2 ∈ {−1,0,1}
hidden reference: rᵢ = 2 only for the responsible hidden unit on a target-2 case; otherwise 0
hidden credit: cᵢ = (rᵢ − hᵢ) / 2 ∈ {−1,0,1}
connection memory: A ← clamp(A + credit × source, −12, 12)
stored weight: w = 0 if A<0, 1 if A=0, 2 if A>0

The responsible unit is determined by the fixed integer routing expression (x₁/2 + 2·x₂/2 + seed) mod width. This only routes backward credit; it never writes a weight. Each architecture begins from its own seeded integer memory and learns every connection through the update above. All widths run exactly 40 epochs for every seed.
